### Principes

- **Local-first.** Si ça peut tourner sur ma machine, ça tourne sur ma machine. Zéro clé d'API, zéro coût récurrent.
- **Ça doit marcher.** Un projet non testé n'est pas fini.
- **Utile > impressionnant.** Le meilleur truc que j'ai construit guide une personne aveugle jusqu'à une porte.
